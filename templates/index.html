AES-256-GCM — EHR content encrypted at rest. Cloud stores only ciphertext.
HMAC-SHA256 — Keywords protected as tokens. Cloud never sees "diabetes".
SHA-256 — Patient identifiers hashed. Cloud stores patient_hash only.
Shamir's Secret Sharing (SSS) — Multi-Authority MPC prevents single points of failure.
Bloom Filters — Hidden policies protect patient consent rules from the cloud.
HMAC-SHA256 — Temporary delegation tokens grant time-limited, role-bound access.
Cryptographic Accumulators — Verifiable search mathematically detects tampering by the cloud.

Multi-Authority MPC — Shamir (2,3) Secret Sharing
A fresh random secret is split into 3 shares (one per hospital). Any 2 shares reconstruct the secret. 1 share alone reveals nothing. This is real Shamir (2,3) over GF(2127−1).

Temporary Delegation — HMAC-SHA256-Signed Time-Limited Tokens
Doctor A delegates temporary access to Doctor B for a specific patient. The token is HMAC-SHA256-signed and includes an expiry timestamp. Consent revocation overrides a valid token.
Protected Access Policy — Prototype Policy Hiding
Prototype Mechanism (not formal CP-ABE): Policy attributes are represented as HMAC-SHA256 commitments. The cloud stores protected identifiers, not plaintext "Hospital_A" or "Doctor" strings.
Blockchain-Free Verifiable Search — HMAC Accumulator
The verification value is bound to both the query AND the result set. Tampering with the results causes verification to FAIL. No blockchain or third party required.

Rules

  • record_id must be unique across all rows — duplicates are rejected.
  • patient_id must exactly match one of the 6 seeded patients (PATIENT_001 … PATIENT_006).
  • hospital_id must exactly match Hospital_A, Hospital_B, or Hospital_C (case-sensitive).
  • keywords are the terms users will search for — include diagnosis-related words.
  • Rows with validation errors are skipped; valid rows are still loaded.
  • Loading a new dataset replaces all existing EHR records and search index.
  • Users, patients, hospitals, and consent policies are not affected.
